# tasks

All work lives here as one file per task, moved between folders as it
advances: `backlog/`, `active/`, `blocked/`, `review/`, `done/`.

## Template

```markdown
---
id: TASK-001
title: Short imperative description
status: backlog
priority: medium
created: YYYY-MM-DD
---

## Context

Why this task exists.

## Definition of done

How anyone can tell it is finished.
```
